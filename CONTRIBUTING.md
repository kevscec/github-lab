# Cómo practicar en este laboratorio

## Preparar un cambio

1. Abre una issue con el problema, el resultado esperado y una forma de comprobarlo.
2. Crea una rama desde `main` para una sola mejora independiente.
3. Edita únicamente los archivos necesarios. Nunca añadas tokens ni datos de trabajo.

## Abrir el pull request

1. Compara tu rama con `main` y abre un pull request.
2. Explica qué problema resuelve y qué comportamiento cambia.
3. Describe cómo comprobaste el resultado. Para documentación, verifica enlaces, rutas y pasos.
4. Lee el diff completo antes de fusionar; confirma que no incluya archivos ajenos al cambio.

## Terminar

1. En este laboratorio, usa un merge commit para conservar el registro del ejercicio.
2. Elimina la rama una vez fusionada.
3. Cierra la issue correspondiente si quedó resuelta.

## Colaboración

Solicita revisión cuando aporte valor al cambio. En proyectos compartidos, respeta sus reglas de protección.
Si otra persona participa en la autoría, acuerda el uso de su nombre y correo antes de añadir `Co-authored-by`.

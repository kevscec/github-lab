# GitHub Lab

Laboratorio personal de kevscec para practicar issues, ramas y pull requests.

## Qué practicar

- Describir una mejora pequeña en una issue y documentar su resolución.
- Crear una rama por cambio y abrir un pull request con un diff fácil de revisar.
- Comprobar los archivos antes de fusionar y eliminar las ramas terminadas.

## Límites

Este repositorio es público: no subir credenciales, datos personales ni información de trabajo.
No se requieren paquetes externos, GitHub Actions ni tokens adicionales para practicar desde la web.
Las prácticas deben aportar documentación útil; no generar cambios repetidos en masa.

## Recorrido

1. Leer esta documentación.
2. Consultar CONTRIBUTING.md para el flujo de trabajo cuando esté disponible.
3. Usar la plantilla de issues para proponer la siguiente mejora.
